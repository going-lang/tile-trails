# Tile Trails — Capacitor Android Fix

This project is aligned to **Capacitor 8.5.2**.

## What was fixed

- `@capacitor/cli`, `@capacitor/core`, and `@capacitor/android` are all pinned to 8.5.2.
- The old incomplete Android platform was removed so Capacitor can generate a complete platform from the installed package.
- Android setup now requires Node.js 22+, matching Capacitor 8 requirements.
- The setup script runs `npm install`, `npm run build`, `npx cap add android`, and `npx cap sync android`.
- The build script syncs web assets and runs Gradle directly to produce a debug APK.
- The old hand-written Android Gradle configuration is no longer used, avoiding mismatches with the Capacitor Android module.

## Build

```bash
npm install
npm run build
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

The debug APK will be at:

`android/app/build/outputs/apk/debug/app-debug.apk`

## Important

The Android platform is intentionally generated by Capacitor rather than checked in as a partially generated/custom copy. This ensures the Android project matches the installed Capacitor version.
