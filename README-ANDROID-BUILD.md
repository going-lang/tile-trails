# Tile Trails - Android APK Build Guide

This document provides complete instructions for building the Tile Trails game as an Android APK.

## Prerequisites

Before building, ensure you have the following installed:

### Required Software

1. **Node.js** (v18 or higher)
   - Download from: https://nodejs.org/
   - Verify installation: `node --version`

2. **Android Studio** (Latest version recommended)
   - Download from: https://developer.android.com/studio
   - Install with default settings

3. **Android SDK** (installed with Android Studio)
   - Android Studio will prompt you to install required SDK components

### Optional (for Windows)
- Git Bash (for running shell scripts)
- Windows 10/11 with WSL2 (alternative to Git Bash)

---

## Quick Start (Recommended)

### For Windows Users

1. Double-click `build-android.bat`
2. Wait for Android Studio to open
3. Follow the on-screen instructions

### For Mac/Linux Users

1. Open terminal in the project directory
2. Run: `chmod +x build-android.sh`
3. Run: `./build-android.sh`
4. Wait for Android Studio to open
5. Follow the on-screen instructions

## Manual Build Process

If you prefer to build manually or the scripts don't work, follow these steps:

### Step 1: Build the Web Game

```bash
npm install
npm run build
```

This creates the `dist/` folder with all the game files.

### Step 2: Initialize Capacitor for Android

```bash
npx cap add android
```

This creates the `android/` folder with the Android project structure.

### Step 3: Sync Web Assets to Android

```bash
npx cap sync android
```

This copies your web game files into the Android project.

### Step 4: Open in Android Studio

```bash
npx cap open android
```

This opens the Android project in Android Studio.

### Step 5: Build the APK in Android Studio

1. **Wait for Gradle sync to complete** (this may take a few minutes on first run)

2. **Build Debug APK:**
   - Go to `Build` → `Build Bundle(s) / APK(s)` → `Build APK(s)`
   - Wait for the build to complete
   - Click "locate" in the notification that appears
   - Your APK will be at: `android/app/build/outputs/apk/debug/app-debug.apk`

3. **Build Release APK (for distribution):**
   - Go to `Build` → `Generate Signed Bundle / APK`
   - Select `APK`
   - Follow the signing process (you'll need to create a keystore)
   - Your release APK will be in `android/app/build/outputs/apk/release/`

## Installing the APK on Your Android Device

### Method 1: Direct USB Installation

1. Enable **Developer Options** on your Android device:
   - Go to Settings → About Phone
   - Tap "Build Number" 7 times
   - Go back to Settings → Developer Options
   - Enable "USB Debugging"

2. Connect your phone via USB

3. In Android Studio, click the "Run" button (green play button)

4. Select your device and click "OK"

### Method 2: Install APK Manually

1. Transfer the APK file to your Android device (via USB, cloud storage, etc.)

2. On your Android device:
   - Go to Settings → Security (or Security & Privacy)
   - Enable "Install from Unknown Sources" (or "Allow from this source")
   - Navigate to the APK file using a file manager
   - Tap the APK file to install

3. Open the "Tile Trails" app from your app drawer

## Troubleshooting

### Build Fails with "SDK not found"

1. Open Android Studio
2. Go to Tools → SDK Manager
3. Install Android SDK Platform 34 (or latest)
4. Install Android SDK Build-Tools
5. Restart Android Studio and try again

### Build Fails with "Gradle sync failed"

1. In Android Studio, go to File → Sync Project with Gradle Files
2. If it still fails, try: File → Invalidate Caches / Restart
3. Check your internet connection (Gradle needs to download dependencies)

### App Crashes on Launch

1. Check Android Studio's Logcat for error messages
2. Verify the web game builds successfully: `npm run build`
3. Re-sync assets: `npx cap sync android`
4. Rebuild the APK

### App Shows Blank White Screen

1. Ensure `npm run build` completed successfully
2. Check that `dist/` folder exists and contains `index.html`
3. Re-run `npx cap sync android`
4. Rebuild the APK

### APK Won't Install on Device

1. Ensure "Install from Unknown Sources" is enabled
2. Check available storage space on device
3. Try uninstalling any previous version first
4. Verify the APK file isn't corrupted (check file size)

### Game Runs Slow on Device

1. The game requires a modern Android device (Android 7.0+)
2. Minimum recommended: 2GB RAM, Snapdragon 600 series or equivalent
3. Close other apps running in background
4. Restart the device if performance is poor

## Release Build Configuration

To create a release APK for distribution:

### 1. Generate a Keystore

```bash
keytool -genkey -v -keystore tile-trails-release-key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias tile-trails
```

Follow the prompts to create your keystore. **Keep this file safe!** You'll need it for future updates.

### 2. Configure Signing in build.gradle

Edit `android/app/build.gradle` and add:

```gradle
android {
    signingConfigs {
        release {
            storeFile file('tile-trails-release-key.jks')
            storePassword 'YOUR_KEYSTORE_PASSWORD'
            keyAlias 'tile-trails'
            keyPassword 'YOUR_KEY_PASSWORD'
        }
    }
    buildTypes {
        release {
            signingConfig signingConfigs.release
            // ... rest of config
        }
    }
}
```

### 3. Build Release APK

In Android Studio:
1. Build → Generate Signed Bundle / APK
2. Select APK
3. Choose your keystore
4. Build release APK

## Performance Tips

### For Better Performance on Low-End Devices

1. Reduce particle effects in `src/game.ts`
2. Lower the render scale in the game engine
3. Disable background music
4. Reduce animation complexity

### For Better Battery Life

1. Lower screen brightness
2. Enable battery saver mode on device
3. Close background apps
4. Use airplane mode (game works offline)
